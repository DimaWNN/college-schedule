# Телеграм бот для расписаний
Удобный Telegram-бот для студентов, который автоматически присылает расписание на сегодня утром, показывает замены и позволяет быстро посмотреть расписание на любой день и неделю, от и для студентов МкИРНИТУ.

### Основные возможности

- 🕗 **Ежедневная утренняя рассылка** расписания в удобное время (настраивается лично)
- 📅 Расписание **на сегодня** и **на завтра** одной кнопкой
- 📋 Полное расписание **текущей** и **соседней** недели
- ⚠️ Отдельный раздел с **актуальными заменами** (с автоматической очисткой старых)
- 📤 **Админ-панель**:
  - Загрузка нового расписания через .xlsx
  - Добавление и управление заменами
  - Удаление старых/всех замен

### Технологии

- Python 3.10+
- Aiogram  3.25.0 (асинхронный Telegram Bot API)
- SQLite — лёгкая и надёжная база данных
- APScheduler — планировщик ежедневных рассылок
- openpyxl — парсинг расписания и замен из Excel-файлов

### Быстрый старт

1. Склонируй репозиторий
2. Установи зависимости:
   ```bash
   pip install \
    aiogram==2.25.2 \
    openpyxl \
    apscheduler \
    python-dotenv               # если захочешь хранить TOKEN в .env
   ```
3. Заполни `config.py`:
   ```python
   TOKEN = "твой_токен"
   ADMINS = [твой_telegram_id]
   ```
4. Запусти:
   ```bash
   python bot.py
   ```

### Структура проекта

```
├── bot.py           # основная логика бота
├── config.py        # токен и админы
├── db.py            # работа с SQLite
├── keyboards.py     # все клавиатуры
├── scheduler.py     # ежедневная рассылка
├── states.py        # FSM-состояния
├── utils.py         # определение верхней/нижней недели
└── xlsx_parser.py   # парсинг расписания и замен из Excel
```

### Поддерживаемый формат Excel-файлов

- **Расписание** — листы с заголовками «Верхняя неделя» / «Нижняя неделя» (или 1/2), столбцы — дни недели, строки — номера пар (имя файла schedule.xlsx)
- **Замены** — простая таблица: столбец A — дата (дд.мм.гггг или гггг-мм-дд), столбец B — текст замен (имя файла replacements.xlsx)
